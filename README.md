# Keera Helm Charts

## Helm Charts

## keera-gateway

The chart can be used to install [Keera Gateway](https://keera.ch/en/gateway) in a Kubernetes cluster.
More detailed documentation can be found in the [Keera Gateway chart directory](https://github.com/ioboi/keera-helm-charts-test/tree/main/charts/keera-gateway).

## keera-agents

The chart can be used to install Keera Agents, which runs AI agents on top of Keera Gateway, in a Kubernetes cluster.
More detailed documentation can be found in the [Keera Agents chart directory](https://github.com/ioboi/keera-helm-charts-test/tree/main/charts/keera-agents).
